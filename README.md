# 🌳 Family Tree Studio

A lightweight, fully responsive, single-file web application built with vanilla JavaScript, HTML5, and CSS3 for building, visualizing, and managing family trees on desktop and mobile devices.

---

## ✨ Features

* **Visual Tree Hierarchy**: Clear, styled ancestor and dynamic child layout.
* **Multi-Tree Management**: Create and switch between multiple independent family trees.
* **Local Persistence**: Saves all your data automatically in your browser's local storage (`localStorage`).
* **Webview/Mobile Friendly Export**: Export backups via direct JSON download or copy raw JSON straight to your clipboard.
* **Import & Restore**: Load previously saved `.json` tree backups at any time.
* **Photo Attachments**: Upload custom profile photos directly to family nodes.
* **Collapsible Branches**: Hide or reveal child branches to navigate large family structures cleanly.

---
